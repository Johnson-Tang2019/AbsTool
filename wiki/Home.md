## What Ab's Tool does

Ab's Tool is a client utility and quality-of-life mod. Current code includes:

- Ominous vault tracking with local handled-state records.
- Furnace input blockage tracking using Servux when available and Jade as an optional fallback.
- A Server Stats page for compatible AbsServerTool protocol-v2 servers.
- An optional server performance-profiler client for compatible AbsServerTool servers.
- Experimental low-ceiling elytra quick launch.
- Experimental Litematica + Iris schematic rendering compatibility on Fabric.
- Optional TweakerMore quick settings and mixed-shulker dominant-item hints.
- Server-shared Xaero waypoints, with the strongest integration in the Minecraft 26.3 line.

Server-side statistics, shared-waypoint authority, persistence, permissions, and profiling are provided by the separate AbsServerTool project.
